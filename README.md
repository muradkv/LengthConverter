# LengthConverter

An iOS app that converts between different units of length: meters, kilometers, feet, yards, and miles.

## 📖 Description

This application is a solution for **Challenge Day 19** of the free [100 Days of SwiftUI](https://www.hackingwithswift.com/100/swiftui/19) course by Paul Hudson.

The challenge is to build an app that takes a number and a unit of measurement from the user and then shows the conversion result in a selected target unit.

## 🚀 Tech Stack

*   **Swift 5**
*   **SwiftUI**
*   **Xcode 15+** 
*   **iOS 18.0+**
